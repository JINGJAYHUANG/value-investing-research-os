# Contributing

Contributions are welcome when they improve the framework without weakening source discipline.

## Pull request rules

1. Do not upload copyrighted books, paid reports, or proprietary datasets.
2. Do not add personal portfolio records, brokerage data, or confidential company information.
3. New named-investor modules must begin as `QUEUED` or `DRAFT` unless the promotion checklist is fully documented.
4. Distinguish source statements from project interpretation.
5. Add or update smoke tests when changing governance behavior.
6. Run `python scripts/validate_repo.py` before opening a PR.

## Good contributions

- stronger evidence-handling rules;
- new company-routing edge cases;
- better memo templates;
- accounting-quality checklists;
- reproducible fictional examples;
- validation automation.

## Out of scope

- stock tips;
- unsupported return claims;
- scraped proprietary research;
- “guru quote” collections without research context.
